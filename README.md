🧵 Confecciones Karina - Sistema de Gestión Fullstack
Proyecto académico desarrollado para modernizar la gestión operativa de una microempresa textil.

🚀 Enlace al sitio en vivo
https://confecciones-karina.vercel.app

🛠️ Tecnologías Utilizadas
Framework: Next.js (App Router)

Base de Datos y Auth: Supabase (PostgreSQL)

Estilos: Tailwind CSS

Despliegue: Vercel

🔑 Instrucciones de prueba
Puedes registrarte como cliente o usar las credenciales de modista (rol 'admin') para acceder al Panel Administrativo y validar pagos.
